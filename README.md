# @petercjl/jqcli

JoinQuant strategy authoring, local checks, historical backtests and attributable result exports. The package includes the CLI and its portable jqcli Skill. It requires Node.js 22+ and Python 3.11+ with pip. JoinQuant credentials are configured separately.

- **Install** · “Install `@petercjl/jqcli` and its Skill for the Agent I am currently using.”
- **Update** · “Update `@petercjl/jqcli` and its Skill for the Agent I am currently using.”
- **Use** · “Use jqcli to check the attached JoinQuant strategy.”

The current Agent selects its own Skill directory and verifies its activated CLI and Skill. See [installation](INSTALL.md) and [updates](UPDATE.md) for the package contract. Strategy changes and backtests use the authorized JoinQuant account and specified target. Paid credits and order actions require separate authorization.
